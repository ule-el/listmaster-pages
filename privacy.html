Privacy policy

Last updated: 3 November 2026.

ListMaster backup is a private tool used only by the owner of the ListMaster project to keep a weekly backup copy of the project's source code in the owner's own Google Drive.

What it accesses

With the owner's permission, the tool uses the Google Drive permission drive.file. This lets it create and manage only the backup files and folder that it creates itself. It cannot see, read or change any other file in the Drive.

What it stores and shares

The tool does not collect personal information about anyone. It does not sell, share or send data to any third party. The only data it handles is the project's source code backup, which goes from the project's private code repository to the owner's Google Drive. The sign-in credentials are kept in the private code repository's protected settings and are never published.

Removing access

The owner can remove the tool's access at any time at myaccount.google.com/permissions.
