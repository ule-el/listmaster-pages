ListMaster backup

ListMaster backup is a small private tool that copies a weekly backup of the ListMaster project's source code to its owner's own Google Drive.

It is used only by the project owner. It is not offered to the public and has no other users.

It asks for one Google permission, "See, edit, create and delete only the specific Google Drive files you use with this app" (drive.file), so it can only see the backup files it creates itself.
